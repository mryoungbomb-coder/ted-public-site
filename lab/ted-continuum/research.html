建议做一个以个人身份为中心的数字门户：外层是精选展厅，中层是可搜索档案，内层是有来源、可迁移的数字分身。丰富内容通过层级逐步展开，首页保持简洁。

这是 2026 年 10 月 17 日的设计研究记录。新版已于 10 月 18 日合并为正式网站；下文保留当时的方案与阶段划分。名称、定位句、服装和形象均为第一版提案。现有公开资料用于展示；原始财务文件、私人数据库和每日工作记录未打包。

01 / 四个模板，四种价值

以下判断来自模板介绍与实际预览的观察；它们是设计参考，不代表购买、复制或授权使用模板资产。

参考值得借鉴在 Ted 网站的用法取舍
Fiber
实际预览		黑白、统一媒体规格、简洁身份与交互作品堆叠。统一精选作品的视觉语法，让作品而非导航占据注意力。保留普通列表入口，避免必须理解 3D 堆叠才找得到内容。
Moreau OS
实际预览		真人背景、桌面图标与统一窗口，把网站变成一个人的空间。档案对象共用详情面板；后续可提供可选探索模式。首页与手机保持普通网页操作；不强制拖拽或层层开窗口。
Videoy
实际预览		电影感影像和明确的作品播放入口。TimeXmart 使用 MIRA 开头的最终版宣传片作为精选影像。不照搬制作公司的客户、奖项和服务结构；点击后播放。
Sequence One
实际预览		大标题、图像气氛与编辑式章节节奏。首屏用名字、肖像和一句定位形成记忆；章节之间留白。避免长加载动画与重复销售模块。作者宣称的性能分数未独立实测。

补充参考：个人存在、知识生长、时间感

Paco Coursey说明少量明确链接也能建立个人存在。Maggie Appleton 的数字花园研究启发按主题和关联组织持续发展的知识。Derek Sivers 的 Now 页面启发一个带日期的近况入口。我们的组合是“人 → 作品 → 关联档案 → 数字分身”，而不是把所有文件平铺到首页。

02 / 新的信息结构

主导航只保留作品、档案、数字分身。关于我融入首屏与身份资料；联系放在页尾。旧页面保留可访问地址，迁移时提供对应入口。

  1. 首页：认识 Ted。名字、真人肖像、可验证的方向介绍。暂定定位：“理解一件事如何运转，再把想法做成作品。”它是品牌文案提案，并非新增工作经历。
  2. 精选作品：理解你如何思考。三个切面分别是房地产建模、TimeXmart 表达、AP 自动化。每个案例展开背景、个人职责、方法、产出、证据和未解决问题。
  3. 完整档案：查到具体内容。项目、文章、影像、生活共用索引，支持筛选、搜索、列表和网格。文章保留完整正文，避免只展示标签和一句摘要。
  4. 数字分身：与留下的材料互动。先展示形象、身份和公开材料检索；未来接入模型时仍返回来源、日期和不确定性。

原型索引接入 6 个公开项目、10 篇长文、41 条视频及 14 张 Instagram 帖子封面，共 71 条。数量描述本次索引范围；不是完整社交资料或私人档案备份。

四条使用路径

访客路径期望获得
第一次认识你肖像与定位 → 三个精选作品快速记住你做什么、有什么独特组合。
招聘或合作项目 → 个人职责 → 方法文章 → 来源分清你完成的工作、可展示的成果和证据边界。
关注创作与生活影像/生活筛选 → 成片/照片 → 原帖看到有风格的作品，顺畅进入 Instagram。
你自己本地日记 → 周复盘 → 案例/知识 → 确认公开每天记录转化成可复用知识，而不是遗失在聊天中。

内容对象与发布路径

每项内容保存稳定 ID、类型、标题、主题、日期、摘要、正文、关联项目、来源、证据状态与可见性。一个预算项目可关联工程量文章、模型方法、决策记录和流程；原始 Excel 留在本地。每日记录先私有，再经你确认形成脱敏周报或案例，最后才进入公开记忆包。

事实、本人自述、推断和建议应明确区分。没有实际材料支持的技能扩展写成方法说明，不写成已经做过的成果。尚未确认的项目金额、客户信息和模型结论不自动公开。

03 / 视觉与交互规则

暖白纸面、石墨黑、少量琥珀色；大衬线标题与清晰的正文形成节奏。真人肖像建立信任，模型图示表达判断力，MIRA 成片表达创造力。首页精选三件作品，完整内容通过索引展开。

  • 桌面采用宽留白和左右关系；手机以单列顺序阅读，筛选不依赖悬停。
  • 统一详情面板，支持键盘关闭、明显的关闭按钮和可见焦点；切换详情时停止上一条视频。
  • 视频点击播放，无声自动播放和阻塞加载动画不作为进入网站的条件。
  • 搜索无结果时给出清晰提示；档案检索未找到材料时说明未知。
  • 正式迁移阶段为详情增加可分享地址、刷新恢复与浏览器后退支持；合并版已为档案详情实现可分享地址、刷新恢复和浏览器返回。
  • 尊重减少动态效果设置；正文可选择、链接可复制。正式上线前再实测对比度、读屏和网络表现。

04 / 数字分身长什么样

当前为第二版国漫造型：清晰线稿与赛璐璐上色，放大头部比例，参考本人照片保留眼镜与发型。暂名 Ted / Continuum：既延续本人，也允许未来改变。保留细框眼镜、浅棕额发和面部辨识度，穿墨黑无领结构外套、暖白内领；一条很细的琥珀色线作为数字身份签名。透明轮廓层暗示记忆的累积，避免用机械盔甲遮住本人。

三个形态共享同一组特征：真人照片用于职业信任；具象数字肖像用于封面和互动；SVG 代码标记用于网站角标与轻量加载。当前已生成概念图和可编辑二维 SVG，未制作 3D 网格、骨骼、动作或声音。

这套形象的主角是你。MIRA 仍属于 TimeXmart 的创作角色，不替代你的个人身份。后续可以先验证头像、半身形象与网站中的小型标记，再决定是否投入实时 3D。

05 / 如何以代码形式存在于网络

可以实现的是身份、经历、作品、表达规则和交互方式的持久数字表示。意识上传并没有在这个项目中实现；一个模型能够模仿表达，也不等于本人具有主观体验或持续存在。

层可迁移内容本次状态
身份profile.json：称呼、公开简介、链接、资料日期已提供示例文件；参考 JSON Resume 的内容/展示分离思路。
记忆JSONL 陈述、来源、时间、公开批准、证据状态已提供格式与少量公开示例，不读取私人库。
表达behavior.json：语气、未知处理、引用与权限边界规则文件已提供；生成模型尚未连接。
外观概念图、SVG、appearance.json二维已提供；3D 与声音尚未制作。
交互公开档案检索 → 展示资料和出处浏览器检索和命令行检索可运行；不代表自由对话。
保存版本、导出、校验、恢复、继承授权已提供代码包和校验；跨地点备份及继承安排待实施。

部署与保存方式

公开站仍可运行在 GitHub Pages；私人材料与日记留在本地，公私之间通过明确审核的导出文件连接。未来模型密钥放在服务端，不放到网页或仓库中；任何模型适配器都可以替换，身份与记忆文件继续保留。

建议目标是三份可恢复副本：电脑上的工作副本、另一设备或加密移动硬盘、异地备份。使用开放格式，维护文件清单与 SHA-256，每季度测试恢复一次，每年检查格式与依赖。这是保存计划，当前没有替你配置异地存储。

W3C DID可以作为未来标识层选项，但不保存人格。IPFS 的 pinning 文档也说明需要持续保留数据副本，内容地址本身不保证永久可访问。美国国会图书馆的个人网站归档建议支持整理文件、保存元数据和多位置副本的做法。

如果以后需要纪念模式，应由你明确指定授权人、可见内容、撤回与停用规则。不能因为你一段时间没有登录，就自动推断死亡或启用代理。未来生成的回答应标注“基于截至某日的档案生成”，不冒充本人实时发言。

06 / 分阶段落地

  1. 本次：确认方向。可交互原型、参考研究、形象概念、公开身份代码包。检查首页是否表达得像你、三个精选是否准确。
  2. 正式网站重构。迁移现有页面、补充稳定详情地址和返回逻辑、保留旧链接；验证全部内容可访问。正式发布前保留当前版本回退点。
  3. 日常记录系统。每日用项目、任务、数量/单位、输入、判断、产出、阻碍、下一步记录；汇总为你可审核的周报。不能从沉默推断完成情况。
  4. 有来源的对话。审核记忆后接入模型，验证事实引用、时效性、未知问题与私有信息隔离。
  5. 具身与长期保存。经你选择再做声音和 3D，配置多副本、恢复测试和授权安排。

正式版本验收目标：访客在短时间内找到一个与你相关的案例；全文、成片和来源入口可用；手机无横向溢出；键盘可完成主要操作；分享链接可刷新恢复；公开导出不包含原始业务资料。这些是后续测试目标，不是本次已测得的性能或转化率。
