WORKBOOK 01 / DEVELOPMENT & FUND MODEL

开发模型：17 张表，各自负责什么？

先整理项目假设与租金底层，再建立建设支出、稳定期收入、债务与退出现金流，最后把项目收益分配到 LP 和 GP。

工作表文件里有什么怎么用于建模
Executive Summary汇总投资规模、股权需求、投资人回报、时间线与项目重点。读取 Project Assumptions 与 OZ Fund Equity Waterfall 的结果，形成投资概要。
Property Information物业与开发项目的基本资料、图片与位置。提供项目背景；公开页面不展示具体地址或交易主体。
Project Assumptions户型、面积、租金、开发成本、施工与稳定期、融资条件、估值及退出假设。把可调整的输入集中在同一张表，供收入、提款、贷款及现金流计算引用。
Stabilization Period Income分户型租金、入住进度、稳定期收入与费用。把单户租金乘以户数，建立从出租到稳定运营的收入。
Projected Cash Flows建设支出、租金、NOI、退出价款、三类融资、利息与本金，以及两层现金流。先算资产层无杠杆现金流，再叠加贷款发放、偿还、融资费和债务服务得到股权现金流。
Assumption Checklist租户、租金、成本、运营和融资假设的支持材料与缺口。记录假设依据、缺少资料、对现金流或债务的影响及跟进负责人。
OZ Fund - Open Items基金结构、条款与需要后续决定的问题。把尚未确定的事项连接到模型假设；讨论事项不当作已完成决定。
Finanical Information ReportSources & Uses、建设贷款与财务信息概要。把资金来源和用途放在一起核对，辅助融资讨论。
DCF AnalysisNOI、终值、折现因子、资产与股权 NPV、敏感性矩阵及折现率推导。先计算经营现金流与净出售收入的现值，再与开发投入比较，并检查退出资本化率和折现率的影响。
Unit Mix户型、套数、面积、单户租金及面积单价。建立租金收入底层明细，避免直接用一笔总收入代替租金表。
Perm Loan Amort. Template长期贷款的期初余额、月供、本金、利息与期末余额。将摊还贷款的债务服务及退出余额连接到股权现金流。
Construction Draw Schedule按工种分配的预算与逐月提款日历。以施工开始日生成月度日期，把建设成本分配到实际资金使用期。
Construction budget总承包、土方、结构、机电等预算及每户成本。分开硬成本、软成本与储备，再汇总开发资金需求。
OZ Fund Equity WaterfallLP/GP 出资、资本返还、优先回报欠款、catch-up、promote 及剩余收益。按顺序处理每层可分配现金；汇总投资人现金流，计算 XIRR、倍数并检查剩余现金。
Fund Terms AssumptionsLP/GP 出资比例、管理费、优先回报、分配比例及持有期。将基金条款作为 waterfall 的驱动输入；文件中的税务项目属于建模假设。
GP EquityGP 出资、管理费、共同投资回报与 promote。区分 GP 自有资本回报和管理/业绩报酬，展示 GP 收益来源。
Const Loan Amort. Template建设贷款的贷款额、利率、期限和还款计算。作为债务计算支持表，与项目资金使用及偿还假设核对。
HOW I MODELED IT

我怎么把这些表连起来？

01 / 建立租金底层

我先按户型整理套数、面积与单位租金，再算月度租金和全年收入。开发模型以面积 × 每平方英尺租金得到单户月租，之后乘以户数。

Project Assumptions!D7 = E7 × C7；收入汇总使用各户型租金 × 各户型套数。
02 / 从收入到 NOI

我把空置/信用损失与运营成本从收入中分开，费用包含税、保险、维修和管理等项目。这样可解释 NOI 变化来自收入端还是费用端。

RTL UW Model：B38 = B28 − B37；即 NOI = Effective Gross Income − Operating Expenses。
03 / 把成本放入时间线

我区分土地、硬成本、软成本、contingency 和融资费用。Construction Draw Schedule 将预算按工种与月份展开，而不是假设建设款一次性花完。

Draw schedule 用施工开始日与 EOMONTH 生成日期；Projected Cash Flows!F40 引用对应月份的建设提款，并以负数表示支出。
04 / 区分资产现金流与股权现金流

我先计算 NOI、土地、建设/软成本及净出售收入构成的无杠杆现金流，再加入收购/再融资、建设及长期贷款的发放、费用、利息、本金和退出偿还。

Projected Cash Flows：row 48 为 Unlevered Cash Flow；rows 61–78 为融资与债务服务；row 81 为 Levered Cash Flow。
05 / 找出真正限制贷款的条件

我分别计算收购 LTV、ARLTV 和 LTC，并把各限制转换为可允许的贷款金额。贷款不能只按最宽松的一项决定。

UW Model!B67 = MIN(B64, B65, B66)：取三种杠杆约束对应贷款额中的最小值。B62 = B51 / B47；B63 = B51 / B20。
06 / 检验债务服务与利息储备

我将利息-only 与摊还贷款分开比较，通过 NOI / annual debt service 检查退出融资的承受能力；建设 carry 则用平均已提款余额估算。

B81 = B51 × B80 × B54 / 12；B82 = B81 × B55。年度摊还债务服务使用 −PMT(月利率, 总月数, 贷款额) × 12。
07 / 用 DCF 与敏感性解释估值

我以 NOI 与退出 cap rate 推导终值，再扣出售成本、按折现率求现值。DCF 页同时展示资产层与股权层结果，以及 discount rate × exit cap rate 和杠杆 × required equity return 的敏感性。

核心关系：Terminal Value = 退出后下一期 NOI / Exit Cap Rate；Present Value = Cash Flow / (1 + Discount Rate)^期数。文件另含 WACC 与风险溢价 build-up 两种折现率推导。
08 / 从项目收益走到 LP / GP 收益

我把基金条款与项目现金流连接，依序处理资本返还、未付优先回报、GP catch-up 和 residual promote。每层扣掉已分配现金后，再进入下一层。

Waterfall!C47 = B47 + C45 − C46：优先回报欠款滚动。C61 = MIN(C59, MAX(C60,0))：仅以可用现金支付欠款。C185 = C181 − C182 − C183：检查总分配平衡。
WORKBOOK 02 / RTL UNDERWRITING

RTL 模型：从项目资料到贷款条款。

工作表文件里有什么怎么用于建模
UW Model成本基础 → 租金与费用 → NOI → cap-rate 估值 → 贷款规模 → 杠杆测试 → DSCR → 利息储备 → scorecard。将借款人的项目资料转换为贷款承销结果。
Construction Budget逐工种成本、每户成本、硬成本占比、软成本与 carry/contingency。汇总贷款的成本分母，并区分实际建设预算与储备。
Guidelines Ref按策略及借款人经验层级组织的内部条件参考。为杠杆测试提供限制条件；公开页不展示内部审批阈值。
Term Sheet利率、费用、期限、首日放款、建设储备、贷款总额与 leverage tests。把承销模型中的选定输入和结果整理成融资条款。
Pricing EngineSOFR、floor、基础 spread、杠杆调整、all-in rate、利息与费用估计。按产品与经验层级选择 spread，再组合利率；需与最终承销利率及 term sheet 核对。

定价引擎怎么做？

先取 MAX(SOFR, SOFR Floor) 得到有效基准利率，再按产品与经验层级选取 spread，并加上杠杆调整。All-in rate = Effective Base Rate + Adjusted Spread / 10,000。Pricing Engine 的输出需与 UW Model 中的贷款利率、费用和 Term Sheet 核对一致。

WORKBOOK 03 / WORK RECORD

工作记录：模型之后，我做了什么？

这个文件记录实际执行：更新承销预算、比较融资、准备 lender conditions、跟进提款与交割，再到保险、供应商和付款流程。

BIDBUY Log / By Business

按工作与业务类别组织行动、责任人、完成记录和后续事项。

Loan checklist

追踪 lender conditions、收入/实体文件、保险、title、贷款与账户资料。

Ramp setup / vendor setup / vendor by account

记录系统配置、供应商邀请、资料收集，以及供应商对应的项目账户。

Vendor ACH / Bills created

记录付款资料、发票、到期、支付状态、审批人与账务分类。公开页不展示任何账户、供应商或发票信息。

RNR COI / Lending COI projects

跟踪保险凭证、additional insured、特定项目所需证明及保险缺口。

Builders’ License / construction draw / FCI Account

追踪执照状态、建设提款、WIP、资金进度、贷款账户与付款跟进。

audit / Closing Check / claims

整理审计、交割与索赔资料的跟进记录。索赔主体、诉讼与金额不展示。

如何把工作反馈回模型？

我用更新的施工预算重新承销，补充 bad debt、concessions、rent loss 和运营费用，再检查建设贷款、土地再融资与长期贷款之间的资金衔接。施工报价、建设周期与 lease-up 的变化会影响现金流和所需股权；融资、提款及交割清单负责把模型中的资金方案落实到资料与执行。
